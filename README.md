# Seevv

AI-powered CV tailoring and career intelligence platform.

## What it does
Seevv helps job seekers understand what a company actually needs (beyond
what the job description says) and intelligently repurpose their CV to
match that need — in their own voice.

## Tech stack
- **Frontend:** React 19, Vite, Tailwind CSS v4 (PWA)
- **Backend:** Node.js, Express
- **Database:** Supabase (PostgreSQL)
- **AI:** Gemini 2.5 Flash + Claude Sonnet (cascade architecture)
- **Hosting:** Vercel (frontend) + Railway (backend)
